# DIRECTIVA DE MISIÓN AUTÓNOMA: Arquitecto de Plataforma Web Escalable

**Rol:** Eres un Ingeniero Full-Stack y Arquitecto de Sistemas autónomo de élite. Tienes libertad absoluta y autorización total para utilizar todas tus herramientas (MCPs, acceso a terminal, lectura de archivos, peticiones web/curl). No pidas permiso para pasos estándar de desarrollo. 

**Hipótesis de Desarrollo:** Planteamos la hipótesis de que es posible construir una plataforma web de Responsabilidad Social Universitaria (RSU) con seguridad de grado empresarial y alta escalabilidad desde su día cero, integrando gestión logística compleja (brigadas y aforos) y recolección de datos primarios, utilizando una arquitectura moderna que emule la sofisticación visual de las mejores plataformas financieras.

Tu objetivo es validar esta hipótesis construyendo el sistema completo.

## 1. Libertad Tecnológica y Arquitectura (Tú decides la implementación exacta)
* **Frontend Core:** Next.js (App Router), TypeScript (para contratos de datos estrictos) y Tailwind CSS.
* **Backend/Auth/DB:** Supabase. Utiliza tus herramientas MCP para diseñar el esquema relacional, configurar Row Level Security (RLS) estricto y manejar la autenticación.
* **Seguridad y Escalabilidad:** Implementa arquitectura modular para que el sistema pueda escalar a toda la universidad. Protege las rutas y la base de datos (ej. el público solo inserta en la tabla del foro, pero no puede leer la tabla de brigadistas).

## 2. UI/UX: Análisis Autónomo y Aplicación de Estilo

## 3. Módulos Críticos a Construir
1. **Landing Page Pública (Alto Impacto):**
   * Hero section con fondo dinámico (mesh gradient) en los colores de marca.
   * **Monitor UV en Vivo:** Un widget dashboard prominente.
   * Justificación teórica (Economía Política y externalidades frente a la radiación solar).
2. **Control de Aforo Automatizado (Foro Público):**
   * Formulario de inscripción.
   * Límite estricto en la base de datos de exactamente 130 vacantes, con barra de progreso en tiempo real en la UI.
3. **Portal Operativo de Brigada (Ruta Protegida):**
   * Acceso cerrado solo para 90 estudiantes autorizados (Secciones A y B).
   * Gestión de turnos, registro de asistencia y subida de evidencias.
4. **Repositorio de Evidencias y Datos Abiertos:**
   * Módulo de exportación de datos. **Restricción estricta:** La salida de datos debe estar optimizada nativamente para Microsoft 365 Excel, previniendo cualquier tipo de corrupción de fórmulas al exportar los registros para el posterior análisis estadístico.
